# Kazi identity

Momentum is Kazi’s rising signal: three steps that represent work moving forward. The symbol sits beside the Kazi wordmark on light surfaces. Installed app icons use a solid dark background.

| Color  | Value     | Use                            |
| ------ | --------- | ------------------------------ |
| Orange | `#FF8A32` | First step and primary actions |
| Pink   | `#E9488B` | Middle step                    |
| Cobalt | `#4263EB` | Tallest step                   |
| Ink    | `#111111` | Wordmark on light surfaces     |
| Dark   | `#151118` | Installed app icon background  |

The identity uses solid fills without shadows, gradients, or decorative edges. Keep the three steps together and preserve the spacing between the symbol and lettering. Workflow status colors keep their existing meanings.

Favicons have transparent backgrounds. App icons are opaque; the maskable variant has extra clearance so the whole signal remains visible when a launcher crops it to a circle. SVG artwork scales to any size. The PNG and ICO exports are generated from the same vector source.

## Refresh animation

Refresh and account loading use the original three symbol paths. Each step rises gently in sequence, then settles back into the complete mark. The animation is available before JavaScript and continues through account verification; page loading uses a smaller version of the same motion.

The symbol scales continuously from 64 to 112 px with the viewport, with responsive spacing, dynamic viewport height, and device safe-area padding. Page loading uses 48 to 80 px. Reduced-motion preferences show the complete, static symbol. The offline state also stops the animation and explains how to reconnect.
